# Library & Information Science (LIS) CBT Practice Examination Portal

A national-standard Computer-Based Testing (CBT) examination web platform for Library & Information Science (LIS) aspirants, inspired by government and recruitment examination interfaces (NTA, SSC, Railway RRB, and Banking IBPS).

Built purely with **HTML5, CSS3, and vanilla JavaScript** (ES6+). Zero external frameworks, zero dependencies, zero backend servers, and zero cloud runtime requirements. Ready for immediate local execution or static deployment via GitHub Pages.

---

## 1. Project Overview

- **Subject:** Library & Information Science (LIS)
- **Examination Name:** LIS CBT Practice Examination
- **Standard Duration:** 90 Minutes (1 Hour 30 Minutes)
- **Question Format:** Multiple Choice Questions (MCQs with 4 options: A, B, C, D)
- **Attempt Size:** Exactly 100 randomized questions per examination session
- **Scoring Scheme:**
  - **Correct Answer:** +1.00 mark
  - **Incorrect Answer:** -0.25 mark (Negative marking)
  - **Unattempted / Skipped:** 0.00 marks
  - **Maximum Possible Score:** 100.00 marks
- **Verification Guarantee:** 100% of questions and answers originate from official printed answer keys in the provided scanned practice sets. **Zero AI-hallucinated or externally invented questions.**

## 2. Key Features

- **Government-Grade CBT Layout:**
  - Blue, white, and neutral-gray visual theme with official test-hall aesthetics.
  - Candidate identification credentials badge and active session tracker.
  - Bilingual interface displaying questions in English and Hindi with an instant language switcher (`English & Hindi`, `English Only`, `Hindi Only`).
- **Cryptographic Fisher-Yates Randomization:**
  - Fresh 100-question selection per attempt drawn from the 386 verified question bank.
  - Shuffled question order and shuffled answer options per question.
  - Option IDs (`A`, `B`, `C`, `D`) remain immutably mapped to their verified truth, ensuring score calculations are decoupled from visual display order.
- **Official 5-State Question Palette:**
  - **Gray:** Not Visited
  - **Red:** Visited but Not Answered
  - **Green:** Answered
  - **Purple:** Marked for Review
  - **Purple with Green Indicator:** Answered & Marked for Review (Evaluated in scoring)
- **Full State Persistence (`localStorage`):**
  - Absolute deadline timestamp countdown.
  - Resilient against accidental page refreshes: reloading resumes the exact in-progress attempt with unchanged question order, answers, review flags, and remaining time.
  - Graceful timeout handling: automatically submits the exam when the timer hits `00:00`.
- **Examination Analytics & Detailed Review:**
  - Official CBT Score Card with net score, gross marks, penalty deductions, time taken, and accuracy percentage.
  - Detailed Question Analysis featuring interactive filters (`All`, `Correct`, `Incorrect`, `Unattempted`).
  - Source tracking badges showing exact source PDF filename, page number, and original question number.
  - Unlimited retakes generating fresh randomized 100-question practice sets.
- **Responsive & Accessible:**
  - Optimized for desktop monitors, tablets, and mobile smartphones.
  - Mobile slide-out palette drawer and sticky bottom action bar.
  - Full keyboard shortcuts (e.g., `Right Arrow` for Next, `Left Arrow` for Previous).

## 3. Question Source Policy & Zero-Hallucination Guarantee

All questions and answers in this repository originate strictly from the scanned practice booklets located in the `questions/` directory:
- `set =1.pdf` through `set 10.pdf` (10 Practice Sets, 100 questions each = 1,000 source questions).
- `qa.pdf` (88-page master booklet containing the 10 constituent sets).

### Strict QA Validation Rules:
1. **Printed Answer Keys Only:** Answers were verified strictly against the printed answer key table located on the final page of each Practice Set.
2. **Rejection of Handwritten Markings:** Handwritten ticks, pencil circles, or student notes on scanned pages were systematically rejected to eliminate scoring errors.
3. **Exclusion of Incomplete Items:** Questions with missing options or OCR split anomalies were safely isolated into [`reports/UNVERIFIED_QUESTIONS.md`](reports/UNVERIFIED_QUESTIONS.md) and excluded from the scored bank.
4. **Zero AI Generation:** No questions or answers were generated by LLMs or external search engines.

## 4. Local Running Instructions

This application is purely static and runs in modern browsers without needing Node.js, Python, or build tools.

### Option A: Local HTTP Server (Recommended)
Running through an HTTP server enables standard browser `fetch()` for `data/questions.json`:
```bash
# Using Python 3 built-in HTTP server:
python -m http.server 8000

# Open your browser and visit:
http://localhost:8000
```

### Option B: Direct Double-Click (`file:///`)
If you double-click `index.html` directly from your file explorer, Chromium-based browsers block local `fetch()` calls. To ensure seamless zero-configuration offline use, the application includes an automatic fallback to `js/embedded-questions.js`:
1. Double-click `index.html` in your file explorer.
2. The examination portal loads immediately and is 100% operational.

## 5. GitHub Pages Deployment Steps

This repository is pre-configured for instant zero-config GitHub Pages hosting:
- Uses relative paths for all assets (`css/`, `js/`, `data/`).
- Includes a `.nojekyll` file in the root to prevent GitHub Pages from ignoring folders or underscores.
- Clean `.gitignore` excluding temporary extraction scripts, OCR images, and large binary artifacts.

### Deployment Instructions:
1. Commit all project files to your Git repository:
   ```bash
   git add .
   git commit -m "Deploy complete LIS CBT Examination Website"
   ```
2. Push to your GitHub repository (e.g., `main` branch).
3. On GitHub, navigate to **Settings** > **Pages**.
4. Under **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `root`
5. Click **Save**. Within 1–2 minutes, your website will be live at `https://<your-username>.github.io/<repo-name>/`.

## 7. Future PDF Addition Workflow

To add new question papers to the question bank:
1. Place the new scanned PDF in the `questions/` directory (e.g., `set_11.pdf`).
2. Transcribe the printed answer key table from the final page into `scripts/verified_answer_keys.py`.
3. Add the PDF entry to `SET_CONFIG` in `scripts/extract_all_questions.py`.
4. Run the extraction pipeline:
   ```bash
   python scripts/extract_all_questions.py
   python scripts/export_embedded.py
   python scripts/run_tests.py
   ```
5. Commit the updated `data/questions.json`, `js/embedded-questions.js`, and reports.

## 8. Known Limitations

- **Practice Environment:** Because this is a client-side static web application intended for candidate practice and self-assessment, answer data is loaded in the browser. It is not designed to replace secure, proctored high-stakes testing halls.
- **OCR Quality in Source Scans:** Highly blurred Hindi conjunct characters or damaged scanned margins in older practice sets were deliberately excluded from scoring to protect answer accuracy.
